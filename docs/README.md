# GOREST PostgreSQL Starter Documentation

This documentation describes the PostgreSQL-focused starter in this repository. For framework APIs and guarantees, see the [GOREST documentation](https://github.com/elsyahtech/gorest/tree/main/docs).

## Guides

1. [Getting started](./getting-started.md) — prerequisites, setup, migration, and startup.
2. [API reference](./api-reference.md) — the active user endpoints and request/response behavior.
3. [Architecture](./architecture.md) — package responsibilities and the user request flow.
4. [PostgreSQL configuration](./database.md) — application database, TLS, mTLS, and test safeguards.
5. [Testing and coverage](./testing.md) — unit tests, PostgreSQL integration tests, coverage reports, and CI setup.
6. [Configuration and deployment](./configuration.md) — environment variables, Redis default, and deployment cautions.
7. [Release checks](./release-checks.md) — repeatable local and CI checks.

The endpoints and sample authentication are starter code. They do not replace application-specific authorization, user lifecycle, or deployment security controls.
